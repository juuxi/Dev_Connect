# Проект DevConnect

Реализует API для блог-платформы с возможностью создания Постов (Posts), Комментариев (Comments) к ним, Уведомлений (Notifications) и "Хлопков" (Claps). 

## Основные архитектурные особенности

- **Кэширование:** выполняется для специального эндпоинта `api/posts/main_feed/`, который "отдает" последние 20 постов. Кэширование выполняется при помощи Redis, данные хранятся на протяжении 5 минут 
- **Логирующий Middleware:** реализован полноценный middleware, сохраняющий время начала обработки запроса при проходе запроса через него и логирующий затраченное на обработку время вместе с запрашивающим пользователем при проходе ответа
- **События при создании комментария:** увеличивается comment_count на соответствующем объекте Поста, создается уведомление для автора Поста

## Signals vs save()

В данном случае переопределение save() является предпочтительным способом решения задачи, поскольку задача относится к основной бизнес-логике приложения.

Сигналы же зачастую используются для декомпозиции (разделения, decoupling) модулей. Основной проблемой использования сигналов является сложность дебага: код начинает "прыгать" между различными частями файла, разными файлами, а то и модулями.
